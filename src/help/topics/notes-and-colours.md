## Notes

Every shape and connector has a **Notes** field in its properties. Use it for details that would clutter the diagram, like owners, versions or open questions.

- A shape with notes shows a small note badge.
- Connector notes are saved with the diagram but not drawn.
- With an API key, **Suggest a note with AI…** offers a note for you to check and accept: see [Suggesting notes](help:suggesting-notes).

## Colours and text

Select a shape to set its **Fill**, **Border** colour and width, and **Text** colour. Select a connector to set its line colour and width. Groups, pools and lanes have a **Fill** and **Border** too: see [Groups and swimlanes](help:groups-and-swimlanes). Font, size, bold, italic and alignment are in the **Text** section: see [Text styling](help:text-styling).

- **Presets** are soft fills and strong lines that suit both light and dark themes, and switch with the theme. There are eleven: Slate, Blue, Teal, Green, Amber, Red, Purple, Yellow, Steel, Tan and Pink.
- **Custom** lets you enter any colour. Custom colours stay the same in both themes.
- **Reset** returns the item to the default style.

> Select several shapes to style them all at once.

## Layer colours

Layered enterprise architecture views often colour each layer the same way. The built-in **Layered EA** stencils and template use these presets (soft for the fill, strong for the border):

- **Business**: Yellow
- **Data**: Teal
- **Application**: Blue
- **Technology**: Green
- **Network**: Steel
- **Strategy**: Tan
- **Motivation**: Purple
- **Implementation**: Pink

Pick the same preset on your own shapes and groups to match them.
